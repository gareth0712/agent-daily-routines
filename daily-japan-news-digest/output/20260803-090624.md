### [Claude Codeの自己改善ループが事故を起こした](https://zenn.dev/tottoko_hamu/articles/2026-07-24-220212)

### [additionalContext には上限がある](https://zenn.dev/radaru/articles/claude-code-additional-context-budget)
*Claude Code 的 additionalContext 存在字元上限*
來源：Zenn - Claude Code｜發布：2026-08-02T17:15:26+09:00

`additionalContext` 是 Claude Code SessionStart hook 用來在對話開始時注入情境資訊的功能，透過 JSON 輸出傳送，但存在字元預算上限。原始實作使用 `text[:BUDGET]` 從文字尾端截斷，導致按慣例放在最後的重要規則靜默消失，且使用者無從察覺。作者實作三種解決方案：為內容區塊指定優先等級（KEEP、DROP_LATE、DROP_FIRST）讓低優先級內容先被捨棄、限制清單只顯示有變動的項目、並明確標示哪些內容被省略。實測顯示底層資料增加 5 倍時，實際注入文字僅從 1,483 增至 1,525 字元，方案可有效擴展。核心教訓是 context budget 管理需要設計「優雅降級（graceful degradation）」機制，而非只是縮短文字。
