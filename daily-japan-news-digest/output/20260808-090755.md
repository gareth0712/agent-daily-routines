來源：Zenn - Claude Code｜發布：2026-08-07 22:38 JST

UserPromptSubmit hook 在每次 prompt 時同步執行，作者的 `cost_guard.sh` 透過呼叫 `ccusage` 外部指令檢查 API token 消耗速率，但實測發現平均延遲達 843ms、最高達 5.3 秒。解決方案是在 `/tmp` 存放 60 秒 TTL 的緩存檔案，**關鍵設計**是「正常情況下也要寫入空緩存」，而非只在發出警告時才寫，確保大多數例行執行直接跳過外部指令呼叫。實作中加入 `gtimeout 5` fail-safe，防止無回應指令阻塞整個 hook pipeline。透過 `hook-latency-wrap.sh` 與 `hook-latency-report.sh` 監控效能指標，驗證改善成效。此方案可推廣至任何需要重複呼叫外部資源的 hook 場景。
