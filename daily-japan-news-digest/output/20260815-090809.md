### [Claude Codeの429は2種類ある](https://zenn.dev/zenn_content/articles/claude-code-429-usage-vs-throughput)
*Claude Code 的 429 錯誤有兩種類型*
來源：Zenn - Claude Code｜發布：2026-08-14 13:15 JST

Claude Code 的 429 錯誤本質截然不同，對處方「完全相反」：**Throughput 限制**是每分鐘速率上限，等幾分鐘自然恢復，解法是降低並行度；**Usage 配額**是 5 小時滾動窗口 + 週配額的總量上限，必須等窗口重置，解法是減少總消耗。診斷方式：遇到 429 先執行 `/usage` 指令，有重置時刻顯示 → Usage 枯竭，等幾分鐘即通 → Throughput 限制。實例：75 個 Subagent 並行執行消耗 5.25M token，同時觸發兩種限制。
