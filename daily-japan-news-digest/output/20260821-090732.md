### [Claude Code の週次レートリミットを回帰で逆算したら、キャッシュ読取がタダだった](https://zenn.dev/crandim_r_and_d/articles/260817_claude_code_weekly_rate_reverse_engineering)
*逆向工程 Claude Code 週次限制，發現快取讀取幾乎免費*
來源：Zenn - Claude Code｜發布：2026-08-20 17:42 JST

作者透過回歸分析對 Claude Code 週次使用量上限進行逆向工程，發現快取讀取（cache read）的消耗幾乎為零，與 API 計費中「0.1x 輸入費率」的設計完全不同。導出的消費公式為：**Δf5/w[%] ≈ 2.75 × cache write(1h)[Mtok] + 27.5 × output[Mtok]**（R²＝0.55），費率主要由快取寫入量和輸出 token 數決定。這意味著長時間維持同一個 session 不會增加每輪消耗成本，主動截斷 session 反而得不償失；唯一值得警惕的是 session 閒置超過一小時後，系統會強制重新寫入完整 context 造成額外消耗。此研究透過使用日誌與實際消耗數據的相關分析，展示了黑盒式使用量限制可被資料科學方法逆向推算。
