### [MCPサーバーのプリミティブ（Tools・Resources・Prompts）の使い分け](https://note.com/study963/n/nfcf1edd59e9e)
*MCP伺服器基本元件（Tools・Resources・Prompts）的使用區分*
來源：note - #ClaudeCode｜發布：2026-09-27 09:02 JST

本文整理自 Anthropic Academy「Introduction to Model Context Protocol」課程第10課（也是最終回）「MCP review」，回顧 MCP 伺服器端三大基本元件的角色分工。`Tools` 由 Claude（模型本身）自主決定何時呼叫，適合用來賦予 Claude 新能力，例如執行程式碼或計算；`Resources` 由應用程式層控制何時取得與如何使用資料，常用於填充 UI 自動完成欄位或補充對話脈絡；`Prompts` 則由使用者透過點擊按鈕、輸入 slash command 等 UI 互動主動觸發，用來啟動預先設定好的工作流程。文中給出簡單的判斷原則：「想讓 Claude 具備新能力就選 Tools」，UI 元件與情境資料交給 Resources，使用者主動觸發的流程交給 Prompts。這種三層分工也對應到整個應用架構：Tools 面向模型、Resources 面向應用程式碼、Prompts 面向終端使用者。
