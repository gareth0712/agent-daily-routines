### [Claude Codeの`/loop`と`/schedule`、同じ「繰り返し」でも実行場所が違う](https://qiita.com/caymezon/items/555517feaa9826d3320f)

來源：Qiita - ClaudeCode｜發布：2026-10-12 08:28 JST

文章整理 Claude Code 的 CI/CD 自動化指令。`/loop` 在本機 session 執行，session 結束就停止（除非用 `/bg` 轉到背景）；`/schedule` 則建立 cloud agent 的 routine，即使本機關機也會持續執行，並支援完整 cron 語法。`/loop` 若指定間隔（如 `/loop 5m /code-review`）就固定頻率執行，未指定則由模型決定等待時間，適合輪詢部署完成。`/schedule` 的子指令包括列出管理、`/schedule create` 與 `/schedule run <name>`（立即試跑），因會產生 API 費用，作者建議先手動試跑再排高頻工作。`/goal` 會不經確認自主執行到達成目標，建議使用可機械驗證的條件（如 ESLint 錯誤清零且 `npm test` 通過）；`/autofix-pr` 處理 CI 失敗、lint、型別錯誤與 PR review 意見，但不處理架構變更、測試預期變更或需外部服務存取的操作。
