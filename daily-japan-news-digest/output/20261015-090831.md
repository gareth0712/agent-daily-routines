### [MCPとは？Claude Codeにつなぐ方法｜claude mcp addの書き方・設定ファイル・安全に使う注意を、実際に動かして解説【2026年10月】](https://note.com/masa_aimaster/n/n097dabeb19e1)
*什麼是 MCP？連接 Claude Code 的方法：`claude mcp add` 寫法、設定檔與安全注意事項（2026 年 10 月）*
來源：note - #ClaudeCode｜發布：2026-10-15 09:04 JST

本文是 MCP 入門，並在 Windows 11 的 Claude Code 上實際新增 server、確認連線並呼叫工具。Claude Code 連接 MCP 有三種方式：官方推薦的 HTTP（`claude mcp add --transport http <名稱> <URL>`，需驗證時加 `--header`）、本機執行的 stdio、以及已被標示為 deprecated 的 SSE（`--transport sse`）。stdio 的關鍵是 `--` 雙破折號：其前為 Claude Code 自身選項（`--transport`、`--env`、`--scope`），其後才是啟動 server 的完整指令，例如 `claude mcp add --transport stdio everything -- npx -y` 加上套件名。傳遞 API 金鑰用 `--env KEY=value`，且 `--env` 後不可直接接 server 名稱，否則名稱會被誤讀為另一組 KEY=value。設定範圍用 `--scope`（`-s`）分為 `local`（預設，存於 `~/.claude.json`）、`project`（共享的 `.mcp.json`）與 `user`；`.mcp.json` 內可用 `${VAR}` 帶入環境變數，避免金鑰寫死。作者提醒僅連接可信任的 server，會抓取外部頁面的 MCP 可能受惡意指示影響，不使用的 MCP 應移除。
