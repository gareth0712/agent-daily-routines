來源：Qiita - ClaudeCode｜發布：2026-10-24 09:05 JST

2026 年 10 月 1 日的 Claude Code v2.1.287 加入 **Mods**：隨 plugin 一起發佈的 JavaScript/TypeScript 函式，可在 Claude Code 行程內部觀察、改寫或攔截 `tool.call`、prompt 送出、`command.run`、UI 繪製等事件，`/diff` 面板已改為內建 Mod `cc-plugin-diff`。最小構成只需 3 個檔案（`.claude-plugin/plugin.json`、`hooks/hooks.json`、`hooks/register.js`），`hooks.json` 有 `modules` 鍵即被視為 Mod；`register(on)` 中以 `on(事件, handler)` 註冊，handler 收到 `$`（Mods API：`$.command`、`$.ui`、`$.process`）、`e`（事件內容）、`next`，回傳 `next(e)` 為觀察、`next({...e, 改寫})` 為改寫、不呼叫 `next` 直接回傳即為攔截。可用 `claude plugin validate` 靜態列出每個事件要做什麼，`claude plugin test` 不需 session 就能跑單元測試；作者在 v2.1.296 實測可用，載入可用 `--plugin-dir` 僅在單一 session 生效。⚠️ Mods **沒有沙箱、以使用者本人權限執行，且可代為核准工具呼叫**，安裝前務必 `validate` 檢查內容，守門用的 hook 要以 `.catch` 倒向「失敗即拒絕」。文件用語上 Mod 的事件處理器稱為「hook」，傳統 settings.json 的則改稱「settings hook」；同月另有 v2.1.299 的閒置自動 compaction 等更新。
