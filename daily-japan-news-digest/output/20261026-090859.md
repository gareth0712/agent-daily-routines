### [Claude Code の Bash は既定 2 分で打ち切られる:BASH_DEFAULT_TIMEOUT_MS で延ばす](https://zenn.dev/aicoding_guide/articles/acg-claude-code-bash-timeout-env)
*Claude Code 的 Bash 預設 2 分鐘就被中斷：用 BASH_DEFAULT_TIMEOUT_MS 延長*
來源：Zenn - Claude Code｜發布：2026-10-26 00:43 JST

整理 Claude Code Bash 工具的三個上限：預設 timeout 2 分鐘由 `BASH_DEFAULT_TIMEOUT_MS` 決定，模型可指定的上限 10 分鐘由 `BASH_MAX_TIMEOUT_MS` 決定，實際生效為兩者較大值。輸出預設截斷在 30,000 字元，超出部分會存成檔案；用 settings.json 的 `bashOutputMaxChars`（4,000〜128,000）調整，一旦設定就會忽略環境變數 `BASH_MAX_OUTPUT_LENGTH`。把這些寫進 settings.json 的 `env` 區塊，優先權高於 shell 環境，不必每次手動帶。作者也提醒：跑不完的指令應改用背景執行而非無限延長 timeout；`cd` 後工作目錄漂移則用 `CLAUDE_BASH_MAINTAIN_PROJECT_WORKING_DIR` 處理。
