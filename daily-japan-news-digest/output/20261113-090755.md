### [Claude Code のインストール後に "claude: command not found" / "~/.local/bin is not in your PATH" と出たときの PATH の通し方(zsh・bash)](https://qiita.com/homhom44/items/0c1ffa5a55683e560423)
*Claude Code 安裝後出現 command not found / ~/.local/bin 不在 PATH 時的設定方法*
來源：Qiita - ClaudeCode｜發布：2026-11-13 06:31 JST

原因是 native installer 把 `claude` 放在 `~/.local/bin` 但不會自動改 PATH。zsh：`echo 'export PATH="$HOME/.local/bin:$PATH"' >> ~/.zshrc` 再 `source ~/.zshrc`；Linux bash 寫 `~/.bashrc`，macOS bash 寫 `~/.bash_profile`，fish / Nushell 依各自語法。檢查：`echo $PATH | tr ':' '\n' | grep -Fx "$HOME/.local/bin"`，再 `claude --version`。懷疑多版本共存用 `which -a claude`；若 `which claude` 與 `claude --version` 都正常，PATH 警告可暫時忽略。
