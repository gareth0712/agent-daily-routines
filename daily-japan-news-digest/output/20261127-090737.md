說明 GitHub Actions 的 `anthropics/claude-code-action` 在 Claude 啟動前失敗的兩種錯誤。⚠️ 錯誤一「native binary not found at /home/runner/.local/bin/claude」：自 v1.0.218（2026-09-08）起 action 改用官方安裝腳本，安裝回報成功但該路徑沒有 launcher，造成 `ENOENT`（issue #1817）；修復 PR #1848 截至 2026-11-27 尚未合併，暫時解法是把 action 固定到先前可用的 commit SHA（如 v1.0.217），同樣設定下會間歇成功或失敗。錯誤二「SDK execution error: process exited with code 1」是通用訊息，issue #892 的原因包括 credit 不足、預設模型 ID 已下架導致 404（需在 `claude_args` 用 `--model` 指定）、以及 `--output-format json` 與 action 使用的 stream-json 衝突。排查三步：固定 SHA；自行安裝後以 `path_to_claude_code_executable` 指定路徑；設定環境變數 `DEBUG_CLAUDE_AGENT_SDK: "1"` 顯示真正錯誤（`show_full_output: true` 對早期崩潰無效）。另提到 review 沒有輸出屬不同問題，需 `pull-requests: write` 與 `track_progress: true`。
